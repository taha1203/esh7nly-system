# ESH7NLY 2.0

نظام إدارة فودافون مع Firebase Realtime Database.

## الجديد
- إدارة الموردين: التجار الذين تشتري منهم الباقات.
- إدارة التجار المشترين: التجار الذين يشترون منك، مع عويس كتاجر افتراضي.
- لكل تفعيل: تحديد المورد + التاجر/العميل المشتري.
- متابعة المستحقات حسب كل تاجر مشتري.
- واجهة Light واضحة عالية التباين.
- تحكم موسع في الهوية والألوان والخلفية والعناوين.
- مزامنة Firebase Realtime.

## Firebase
Realtime Database URL:
https://esh7nly-62354-default-rtdb.firebaseio.com/
